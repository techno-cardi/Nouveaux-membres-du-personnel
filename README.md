# Guide express du personnel - Cardinal-Roy

Guide statique destiné aux nouveaux membres du personnel de l’École Cardinal-Roy.

- `index.html` : page principale
- `styles.css` : mise en page
- `logo.css` : logo officiel fourni par l’école
- `script.js` : recherche instantanée et navigation

## Publication GitHub Pages
Dans **Settings > Pages**, choisir **Deploy from a branch**, puis `main` et `/ (root)`.
